13. Frequently Asked Questions

Q: I'm an Engineer and I see no tickets. Why?

A: Engineers only see tickets that are engineering-related (Feasibility, Design Review, IFC Planning, Grid, Battery, Site Assessment, Full EPC) or tickets where you're assigned to a spawned work item. If you expect to see a ticket, ask the PD owner to assign you as the designer or assign you to a work item.

Q: Can I edit someone else's ticket?

A: Only the ticket creator, the assigned Project Developer, or an Admin can edit a ticket. If you need a change made, contact the ticket owner.

Q: What happens after a handover is accepted?

A: The project automatically transitions to "PM Active" phase, execution is enabled on the project spine, and the PM can start managing the project in the PM module. The PM can also add an Excel tracker link.

Q: Can a rejected handover be resubmitted?

A: Yes. After rejection, the handover goes back to DRAFT status. The PD owner reviews the rejection reason, fixes the issues, and can submit again. There's no limit on resubmissions.

Q: How do I see metrics for a previous financial year?

A: The Reports page currently defaults to the current FY. Contact your admin if you need historical FY data.

Q: What is the evidence score threshold?

A: The evidence score measures how much supporting documentation has been attached. If the score is below the threshold, an authorized user (PM/COO/CEO) can override it with a reason.

14. Getting Help

If you need help with the PD module:

  • System issues: Contact your system administrator
  • Process questions: Contact the PD team lead
  • Handover questions: Contact the assigned PM or PD owner
