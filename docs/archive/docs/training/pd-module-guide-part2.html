5. Creating a PD Ticket (Step-by-Step)

Creating a ticket is a 3-step wizard. You must complete each step before moving to the next.

ℹ️
Who can create tickets? Project Developer COO / CEO / Admin

How to Start

Click the "+ New PD Ticket" button from the Dashboard or Tickets page.

Step 1 of 3 — Select a Client

1

Search for the client

Start typing the client name. The list filters as you type. Click on a client to select it.

2

Client not found? Create a new one

Click "+ Create New Client", type the name, and click "Create Client". The system generates a unique Client ID (e.g. EE-C0042) automatically.

3

Click Next

Once a client is selected (shown in a green box), click Next to proceed.

1

Search for the project

Type the project name. The list shows matching projects with their current phase.

2

Creating a new project?

If the project doesn't exist, click "+ Create New Project". The system will warn you if a similar project name already exists to avoid duplicates.

Required Fields (marked with *)

FieldWhat to Enter
Project / Site NameThe name of the site or project
Request TypeWhat kind of work: Cost Proposal, IFC Planning, Site Assessment, Feasibility Study, Grid Application, Design Review, Battery Assessment, or Full EPC
Due DateWhen this ticket should be completed (for SLA tracking)

Optional but Recommended

  • Priority — Critical, High, Medium (default), or Low
  • Size (kWp) — System size helps engineers scope work
  • Financial Estimates — Estimated project value and cost. Margin calculates automatically.
  • Engineering Tasks — Pre-built task templates appear based on Request Type. Select which tasks to spawn.
✅
What happens when you click "Create PD Ticket"?
  1. The ticket is created with a unique ID
  2. Selected engineering tasks are automatically spawned as work items
  3. The ticket status starts as "Draft" (or "In Progress" if tasks were spawned)
  4. You're taken to the ticket detail page

6.1 Filtering

  • Search box — Searches across project name, client name, and developer name
  • Status dropdown — Filter by: Draft, In Progress, On Hold, Completed, Cancelled
  • Priority dropdown — Filter by: Critical, High, Medium, Low
  • Type dropdown — Filter by request type (Cost Proposal, IFC Planning, etc.)

7.1 Editing a Ticket

1

Click "Edit" in the top-right corner

The page switches to edit mode. Fields become editable.

2

Change the fields you need

You can update: Status, Priority, Due Date, Reworks count, Linked Project, Comments, and Financial Estimates.

3

Click "Save"

Changes are saved immediately. A confirmation toast appears. Click "Cancel" to discard changes.

7.2 Spawning Engineering Tasks

If tasks haven't been spawned yet, you'll see a "Spawn Tasks" button. Click it to create work items based on the ticket's request type.

⚠️
Tasks can only be spawned once After spawning, the button disappears. The spawned tasks appear in the Engineering Tasks section and are also visible in the Engineering module.

7.3 Understanding the Tasks Section

  • Progress bar — Shows overall completion percentage
  • Status counts — How many tasks are Complete, In Progress, On Hold, To Do
  • Click any task row — Jumps to the Engineering Tasks page for that specific task
  • Overdue tasks — Highlighted with red background
  • On Hold tasks — Show the hold reason in orange text
