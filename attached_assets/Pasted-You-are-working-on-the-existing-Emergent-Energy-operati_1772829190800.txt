2. UNASSIGNED TASK ROUTING LOGIC

Implement or correct routing logic for unassigned tasks.

Rules:

if a task is linked to a project and the project has a Project Manager, it should surface under that Project Manager’s operational scope

if a task is linked to a project but no Project Manager is assigned, it must surface as an exception under the Program Manager and COO dashboards

if a task is not linked to a project, it must not clutter normal PM work views and should instead surface in COO / Program Manager triage or exception views

unassigned work should be treated as a management exception, not a standard user task list item

Ensure this logic applies consistently in:

My Work / My Tasks
