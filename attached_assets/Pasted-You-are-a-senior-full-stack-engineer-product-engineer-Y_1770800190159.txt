A) BUILD A SCENARIO / OVERRIDE ENGINE (FOUNDATION)
========================================================
Before touching UI, implement a scenario system that every what-if tool uses.

Data model (DB tables):
1) scenarios
- id (uuid)
- name
- description (optional)
- created_by
- created_at
- is_default (bool)

2) date_overrides
- id (uuid)
- scenario_id (fk scenarios)
- entity_type ENUM('expense_line','expense_invoice','expense_po','inflow_line','project_milestone','project_keydate')
- entity_id (stable ID, see below)
- field_name ENUM('invoice_date','payment_date','receipt_date','start_date','commissioning_date','handover_date', etc)
- override_date (date)
- reason (required)
- created_by
- created_at

Stable IDs (required):
- expense_line_id = hash(ProjectName + TrackerLocator + ExpenseCategory + ExpenseLineItem + Amount + ExpenseInvoiceNumber + ExpenseInvoicedDate)
- inflow_line_id = hash(ProjectName + MilestoneDescription + MilestoneAmount + MilestoneInvoiceNumber + MilestoneInvoiceRaisedDate)
- expense_invoice_id = normalize(invoice_number) + supplier(optional) + project(optional) hash (must be stable)
- expense_po_id = normalize(po_number) hash

Effective dates logic:
- For any line, compute effective_* dates = override date (if exists in selected scenario) else imported date.
- Baseline scenario = “no overrides” (scenario_id = null) OR a default scenario with no overrides.

Expose Scenario selector in UI header on the 3 pages:
- Baseline
- + Create scenario
- Duplicate scenario
- Reset scenario (clear overrides)

========================================================

  - Committed (PO not invoiced)
  - Planned (no PO)

- Supplier (if available)
- Project(s)
- Invoice date (effective)
- Payment date (effective)
- Amount
- State (Planned/Committed/Invoiced/Paid)
- Month bucket (which month it lands in, based on effective payment date for realised; based on invoice date/payment date rule for forecast)
- Actions:
  - Edit invoice date
  - Edit payment date
  - Shift +7/+14/+30 days
  - Drag to month (see below)

Drag-to-month:
- Allow dragging an invoice row onto a month “bucket” strip (Jan/Feb/…).

Acceptance criteria:
- I can search invoice # and edit its date.
- When i push an invoice date out, COS moves months immediately.
- I can see the long-term chart change.
- I can drill down from month → invoices → line items and reconcile amounts.
