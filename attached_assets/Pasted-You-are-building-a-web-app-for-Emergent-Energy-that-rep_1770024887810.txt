Excel parsing requirements (non-negotiable)
- Do NOT assume row 1 is headers. Ever.
- Implement robust header detection per sheet:
  - Scan top N rows to find the best header row based on keyword matches.
  - Case-insensitive, trim whitespace, tolerate merged cells and title rows.
  - Support duplicate header names by indexing them (Status_1, Status_2, etc).
- Implement fallback:
  - If mapping confidence is low, still show the raw sheet as a scrollable table (no empty UI).
- Store parse diagnostics per upload per sheet:
  - detected header row index
  - matched column mapping (which source column → which canonical field)
  - % rows with non-empty primary field (e.g. Task Description)
  - warnings/errors
