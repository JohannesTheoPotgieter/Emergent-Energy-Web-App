IMPORTANT TECHNICAL CONSTRAINT (must be documented in Discovery and UI):
- Browsers do NOT expose the true Windows absolute file path for security reasons.
- Many browsers return “C:\fakepath\filename.ext”.
- Therefore implement “Local File Reference” storage as:
  - browser_provided_path_string (often fakepath)
  - file metadata (name, size, last_modified)
  - and optionally a computed_full_path if a “Local Sync Root” is configured in Settings.

DO NOT build Graph or SharePoint browsing. Purely local selection + stored reference.

Settings (COO_ADMIN only):
- Add “Local Sync Root” text fields (optional):
  - global_default_sync_root (e.g., "C:\Users\...\OneDrive - Emergent Energy\")
  - per-role override (optional)
This allows computing a “full path reference” = sync_root + file_name (or relative path if available).

Task attachments table:
engineering_task_attachment:
