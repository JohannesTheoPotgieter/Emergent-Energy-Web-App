CONTEXT

GOAL

1) Project Development %,
2) Engineering %,
3) Quality %,
4) Project Management %,
5) Tracker linked status (linked/not linked),
6) Project Developer (PD),
7) Project Manager (PM) ONLY if linked/assigned,
