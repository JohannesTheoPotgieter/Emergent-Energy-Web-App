4) Sync engine + scheduling
Implement:
- A scheduled job (every N minutes from settings) that:
  A) creates a leave_runs row (status=running)
  B) fetches approved leave from PaySpace for the configured date window
  C) for each record:
     - compute source_hash (sha256 of key fields)
     - if new external_leave_id: create leave_events row and ledger event_type=created
     - if existing but hash changed: update leave_events and ledger event_type=modified
     - if previously present but missing now OR status cancelled: mark cancelled and ledger event_type=cancelled
  D) update ledger rows to import_status=applied (or failed with error)
  E) finalize leave_runs with status + summary_json
- Manual triggers:
  - POST /api/admin/leave/sync-now (ADMIN)
  - POST /api/admin/leave/retry-failed (ADMIN)
