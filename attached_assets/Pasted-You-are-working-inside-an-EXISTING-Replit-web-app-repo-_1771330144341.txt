Post-mortem metrics (scoring rules like Excel)
- Commissioning pass rate: input choice 1/2/3 -> score 1 / 0.5 / 0.33
- Snag count: score = (100 - (count*10))/100
- Snag completion MTTR (days): score = (100 - (days*12.5))/100
- Contractor quality score = average(commissioning pass rate, snag count score, snag MTTR score)
- Pre-engineering - PVSol (count): score = (100 - (count*15))/100
- Engineering Pack revisions (count): score = (100 - (count*15))/100
- Construction challenges (count): score = (100 - (count*15))/100
- Time to complete EP (days): score = (100 - (days*2.5))/100
- Engineering quality score = average(these four)
- Red flag threshold: any core score < 0.85 -> mark red and show in dashboards.

Warning engine rules (NO hard blocks)
Implement a service that recalculates warnings when:
- checklist item changes
- risk answers change
- plan milestones/tasks change (if linked)
- nightly scheduled job (safety net)

Create or update warnings:
1) Overdue item: end_date < today AND approved=false AND is_applicable=true -> High or Med depending on phase (Commissioning/Handover default High)
2) Invalid dates: start_date exists AND end_date exists AND end_date < start_date -> High
3) Missing evidence: item approved=true AND item is_evidence_required=true AND no evidence_url -> High
4) Risk triggers: based on risk yes/no rules above -> High/Med
5) Phase incomplete near milestone:
   - if a plan milestone due within X days (default 7) and linked checklist phase < 100% approved -> High warning linked to that plan item
NOTE: This must never block completion. Only show bright red indicators.
