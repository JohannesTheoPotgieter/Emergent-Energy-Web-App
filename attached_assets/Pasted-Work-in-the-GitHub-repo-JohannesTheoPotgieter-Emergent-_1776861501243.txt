Objective:
Debug, fix, and harden the Pipedrive integration in this repo so it is reliable, future-proof, and aligned to Emergent Energy’s business rules.

Critical business rules:
- Pipedrive is the CRM source of truth.
- Sync is one-way only: Pipedrive -> app.
- Do not write back to Pipedrive.
- Do not overwrite app-owned operational fields unless there is an explicit source ownership rule.
- Do not break existing working functionality.
- Verify current state before changing anything.

Known issue from admin UI:
- Pipedrive sync is connected.
- Sync run shows high failures.
- Repeated errors appear to happen around client lookup / resolution using pipedrive_org_id.
- This suggests likely schema drift, bad field assumptions, null/type handling, brittle mapping, or broken upsert logic.
