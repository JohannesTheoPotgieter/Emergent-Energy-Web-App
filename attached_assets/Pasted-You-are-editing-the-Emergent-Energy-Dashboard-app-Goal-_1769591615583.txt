1) Expenditure Breakdown sheet
- Sheet name: "Expenditure Breakdown"

- Data starts at row 6.
- Important columns by letter:
  L No
  M ExpenseCategory (Product/ Service)
  N ExpenseLineItem (Description of Work)
  O ExpenseQTY
  P ExpenseRateUnit
  Q ExpenseActualTotal
  R ExpensePONumber
  S ExpenseInvoiceNumber
  T ExpenseInvoicedDate
  U RevenueAmount
  W ExpensePaymentDate
  X COSAmount

2) Revenue Tracking sheet
- Sheet name: "Revenue Tracking"
- Header row is row 12.
- Headers exist at these columns:

  E "%"

  L "INVOICE NUMBER"
  N "INVOICE RAISED DATE"
  P "PAYMENT RECEIVED DATE"

- Data starts row 13.

  - column B contains "KEY:" (starts with KEY),
  - or column C contains "end of sheet",
  - or another header row appears (B == "No." and C contains "PAYMENT MILESTONE") after the first header.
- Coerce dates: values may be Date objects OR strings like "16/01/2026". Support dd/mm/yyyy parsing.

4) ProjectInfo fields:

  If DB is already set up (Drizzle/Postgres), create tables:

B) APIs
1) GET /api/overview
- total_program_budget = SUM(project_info.contract_value) (fallback: sum inflows.VALUE)
- actual_spend_paid = SUM(program_expense.expense_actual_total where expense_payment_date not null AND expense_payment_date <= today)
- revenue_realised = SUM(program_inflows.milestone_amount where payment_received_date not null AND payment_received_date <= today)
- active_projects = count distinct project_name
- include data_as_of = now

2) GET /api/projects-summary

- Size (size_kwp)
- PD, PM
- Cost Proposal Signed (null placeholder)
- Funding Signed (null placeholder)
- EPC Contract Signed (null placeholder)
- Phase - Manual (phase)
- PD Handover date (null placeholder for now)
- Construction Start date (null placeholder for now)
- Duration (null placeholder for now)
- kW/Week (null placeholder for now)
- Commissioning Date (null placeholder for now)
- O&M Handover Date (null placeholder for now)
- Client Handover Date (null placeholder for now)
- Project % Complete = avg(project_plan.actual_pct_complete) for that project
- Expected % Completed = avg(project_plan.expected_pct_complete)
- Delta vs Expected = Project% - Expected%
- Actual Revenue = SUM(program_inflows.milestone_amount) for that project (no paid filter; matches Excel)
- Actual Expenses = SUM(program_expense.expense_actual_total)
