APPLICATION-WIDE UX + FLOW OVERHAUL

Context:
We have a fully working operational platform for a solar EPC company (Emergent Energy). The system contains modules such as:

- Home
- My Work
- Exec
- Project Management
    - Execution Board
    - Project Summary
    - PM Dashboard
    - Smart Import
    - Excel Updates
    - Portfolios
    - Weekly Reviews
- Project Finance
    - Cashflow
    - COS Tracker
    - Procurement
    - Invoice Patterns
- Project Development
- Engineering
- Governance
- Information
- Admin

The system works functionally but the UX feels like disconnected dashboards. We need a **complete UX and interaction overhaul across the entire application** so it behaves like a coherent **project operations platform**.

DO NOT break existing functionality, routes, permissions, or APIs.

This is primarily:
- UX architecture
- layout consistency
- design system
- navigation flow
- component standardization

Not backend logic changes.

--------------------------------------------------

PRIMARY OBJECTIVE

Transform the system from a collection of dashboards into a **project-centric operational platform**.

The application must revolve around **Projects as the core object**.

Every module should clearly answer:

- What project am I looking at?
- What phase is it in?
- What actions are required?
- What risks exist?
- What financial state exists?
